# 🧠 OBT Quantifier — Objective Biomarker Tool for Tremor Analysis

A computer vision–based web application for quantifying hand tremors using FFT frequency analysis and MediaPipe hand tracking. Built as an Experiential Learning project at **RV College of Engineering**.

***

## 📌 What It Does

- Records or uploads hand tremor videos via webcam
- Tracks hand landmarks using MediaPipe (21 keypoints per hand)
- Applies Fast Fourier Transform (FFT) to extract tremor frequency
- Classifies tremors into **Parkinsonian Range (3–7 Hz)** or **Essential Tremor Range (7–12 Hz)**
- Saves sessions for longitudinal tracking and before/after comparison
- Visualizes spectrogram, waveform, and hand asymmetry data

## ⚙️ Prerequisites

### System Requirements
- Python 3.10+
- Node.js 18+
- npm or yarn
- **ffmpeg** (required for `.webm` to `.mp4` conversion from live recordings)

### Install ffmpeg

**Windows:**
```bash
winget install ffmpeg
```
Or download from https://ffmpeg.org/download.html and add to PATH.

**macOS:**
```bash
brew install ffmpeg
```

**Linux (Ubuntu/Debian):**
```bash
sudo apt install ffmpeg
```

## 🚀 How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/obt-quantifier.git
cd obt-quantifier
```

***

### 2. Backend Setup (FastAPI + Python)

```bash
cd backend
```

**Create and activate a virtual environment:**

```bash
# Windows
python -m venv venv
venv\Scripts\activate

# macOS / Linux
python3 -m venv venv
source venv/bin/activate
```

**Install dependencies:**

```bash
pip install fastapi uvicorn python-multipart opencv-python mediapipe scipy numpy
```

**Start the backend server:**

```bash
uvicorn app:app --reload --host 0.0.0.0 --port 8000
```

The API will be available at: `http://localhost:8000`

> API docs (auto-generated by FastAPI): `http://localhost:8000/docs`

***

### 3. Frontend Setup (React + Vite + TypeScript)

Open a **new terminal window**:

```bash
cd frontend
npm install
npm run dev
```

The app will be available at: `http://localhost:5173`

***

### 4. Open the App

Navigate to **http://localhost:5173** in your browser.

> Make sure both the backend (port 8000) and frontend (port 5173) are running simultaneously.

## 🧪 Running a Diagnostic Session

1. Click **New Diagnostic** from the sidebar
2. Enter a Patient ID (e.g. `PT-001`)
3. Choose **Live Camera** or **Upload Video**
4. For live recording: click **Start Recording**, hold your hand in front of the camera for 5–10 seconds, then click **Stop**
5. Click **Analyze** — results appear within a few seconds
6. Click **Save Session** to store the results

## 🔬 How the Analysis Works

1. **Video ingestion** — `.webm` files from live recording are converted to `.mp4` via ffmpeg
2. **Hand tracking** — MediaPipe detects up to 2 hands and outputs 21 landmarks per frame
3. **Signal extraction** — Relative Y-position of index fingertip (landmark 8) vs wrist (landmark 0) is tracked frame-by-frame
4. **FFT** — A Hann-windowed Fast Fourier Transform converts the displacement time-series to frequency domain
5. **Classification** — Peak frequency in the 3–12 Hz band is compared to clinical thresholds:
   - **3–7 Hz** → Parkinsonian Range
   - **7–12 Hz** → Essential Tremor Range
   - **Below threshold** → No significant tremor

## ⚠️ Known Limitations

- Requires good lighting and a stable camera angle for accurate tracking
- Detects hand tremor only — not head, voice, or leg tremor
- Not validated on a clinical dataset — intended as a screening and monitoring tool
- Single camera provides 2D tracking only (no depth)
